Megan (Helpdesk Admin) registered only security questions and can't use SSPR. Standard users can. Why?

A

SSPR is disabled for admins by default

Admins use a fixed two-gate policy, no security questions

C

Nested groups aren't supported

D

Tenant must migrate to the Authentication methods policy

Por qué

Las cuentas con rol admin usan two-gate: dos métodos, sin security questions, y no se cambia. Por eso Learn dice: prueba SSPR con un usuario sin rol.

A. Al revés: SSPR para admins viene habilitado.

C. SSPR sí soporta nested groups, y Megan ya es miembro directo.

D. Al revés: las security questions solo viven en la política legacy de SSPR.
