Trampa 6 · Windows Hello y Entra Kerberos

Kerberos sin PKI

"Cloud Kerberos trust: cero PKI. Entra Kerberos en Azure Files: cero MFA para esa app."

WHfB híbrido con cloud Kerberos trust

  1. Crear el objeto Microsoft Entra Kerberos con Set-AzureADKerberosServer.
  2. Activar "Use cloud trust for on-premises authentication".
  3. Enrolar con línea de vista al DC la primera vez. Si "Use certificate" está activo, gana certificate trust.

Azure Files con Entra Kerberos

  1. Habilitar Entra Kerberos en el storage account y dar admin consent a su app.
  2. Clientes con CloudKerberosTicketRetrievalEnabled.
  3. Un solo identity source por storage account, y la app del storage se excluye de las políticas de MFA.

Learn: MFA incompatibility for Azure Files · Delata: "no PKI", "FSLogix", "profile containers fail to mount"
