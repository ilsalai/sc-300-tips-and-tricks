Solo desde el PAW

Azure Service Management API only from PAWs (extensionAttribute1 = PAW). Unregistered devices must be blocked. Policy?

A

Include filtered PAW devices, Block

Exclude filtered PAW devices, Block

C

Include filtered PAW devices, Require MFA

D

Admin Portals, Windows, Require hybrid joined

Por qué

El patrón de Learn: excluir los devices que cumplen el filtro y bloquear todo lo demás. Un device no registrado es null, no lo excluye el operador positivo, y queda bloqueado.

A. Bloquearía justo a los PAW.

C. El filtro positivo no aplica a devices no registrados, y MFA no restringe a PAW.

D. Admin Portals no es Azure Resource Manager, y hybrid joined no significa PAW.

Debrief de 45 segundos. Frase clave: "Excluye el PAW y bloquea el resto: un device no registrado es null, y null no se excluye". Si muchos eligieron A, es la confusión de include vs exclude en el filtro.
