OAuth no es OATH

"OAuth es el token, OATH es el código de 6 dígitos. ¿Quieres forzar reauth? Sign-in frequency, no token lifetime."

2021

Desde el 30 de enero de 2021 el refresh token y el session token lifetime ya no se configuran. MaxAgeMultiFactor se ignora.

10 min a 24 h

AccessTokenLifetime solo mueve access, ID y SAML tokens. Al vencer, el refresh token renueva en silencio: el usuario no vuelve a escribir nada.

Sesión

Sign-in frequency fuerza reauth. Persistent browser session exige All resources y le gana al "Stay signed in?". Apaga Remember MFA antes.
