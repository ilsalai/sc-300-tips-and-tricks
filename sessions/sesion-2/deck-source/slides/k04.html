Los perfiles dejaron de montar

AVD + FSLogix on Azure Files with Entra Kerberos. Profiles stopped mounting after an MFA policy for All resources. Fix?

Exclude the storage account app from the MFA policy

B

Add on-prem AD DS as a second identity source

C

Add the kdc_enable_cloud_group_sids tag

D

Configure a Kerberos realm mapping

Por qué

Learn lo marca como limitación: Entra Kerberos para Azure Files no soporta MFA. La app del storage account se excluye de las políticas de MFA.

B. Un storage account acepta un solo identity source.

C. Ese tag es para cloud-only y el límite de group SIDs.

D. El realm mapping es para convivir con AD DS, no arregla un bloqueo de CA.

Learn: MFA incompatibility for Azure Files
