Seis meses, solo cuando se necesite

Helpdesk leads need User Administrator only when needed for a 6-month project, then lose it without cleanup. Assignment?

A

Active, permanent

B

Eligible, permanent

Eligible, time-bound, ending with the project

D

Active, time-bound, ending with the project

Por qué

Eligible: activan el rol solo cuando lo necesitan (JIT). Time-bound con fecha de fin: la elegibilidad termina sola al acabar el proyecto.

A. Tendrían el rol siempre activo y para siempre.

B. Nunca vence. Alguien tendría que quitarla a mano.

D. Tendrían el rol activo los seis meses completos, sin JIT.
