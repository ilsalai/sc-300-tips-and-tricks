Un claim con Survey.Create

Tokens must carry a claim with value Survey.Create. Admins will grant it to users and groups. What do you configure?

A

A scope named Survey.Create in Expose an API

B

A groups claim in Token configuration

App role (Users/Groups, value Survey.Create), assigned in Enterprise apps

D

A custom Microsoft Entra directory role named Survey.Create

Por qué

Un app role con Allowed member types Users/Groups sale en el claim roles con el Value que definiste. Luego lo asignas en Enterprise apps.

A. Un scope es un permiso delegated: sale en scp, no es el rol del usuario.

B. Manda object IDs de grupos; el código tendría que mapearlos.

D. Los roles de directorio administran Entra, no la lógica de tu app.
