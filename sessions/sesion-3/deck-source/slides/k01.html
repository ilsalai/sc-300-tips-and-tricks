Graph para una managed identity

FuncHR's system-assigned managed identity needs the Graph application permission User.Read.All. How do you grant it?

A

App registrations: add it and select Grant admin consent

App role assignment from the Graph SP to the identity's SP

C

Reader Azure role on the subscription

D

Enterprise applications: add it on the Permissions page

Por qué

Una managed identity solo tiene service principal, sin application object. Los permisos de Graph se dan directo a su SP con una app role assignment.

A. La managed identity no aparece en App registrations: no hay API permissions.

C. Azure RBAC da acceso a recursos de Azure, no a datos de Graph.

D. La página Permissions muestra y revisa permisos; no los agrega.
