Pedir aprobación desde el prompt

Users can't consent to an unverified app and have no way to ask for it. Enable requests without weakening security?

A

Change user consent to Allow user consent for apps

B

Classify the requested permission as low impact

C

Disable risk-based step-up consent

Turn on the admin consent workflow and select reviewers

Por qué

El admin consent workflow deja que el usuario pida aprobación desde el prompt. La solicitud llega a los reviewers y no cambia lo que el usuario puede consentir.

A. Quita la protección de verified publishers: baja la seguridad.

B. Aunque fuera low impact, el publisher sigue sin estar verificado.

C. No es la causa del bloqueo, y apagarlo reduce la seguridad.

Learn: Enable the admin consent workflow

Debrief de 45 segundos. Contexto del banco: el tenant solo permite user consent para verified publishers con permisos seleccionados, y la app pide Files.Read delegated.
