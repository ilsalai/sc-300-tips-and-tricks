App Proxy con least privilege

Marta must publish apps with Application Proxy, create connector groups and set up SAML SSO. Least privilege role?

A

Cloud Application Administrator

Application Administrator

C

Application Developer

D

Global Administrator

Por qué

Application Administrator administra enterprise apps y app registrations más Application Proxy. Es el least privileged para App Proxy y connector groups.

A. Tiene lo mismo excepto Application Proxy. Esa es toda la diferencia.

C. Solo registra apps. No toca App Proxy ni SSO de apps ajenas.

D. Puede todo, pero rompe least privilege.
