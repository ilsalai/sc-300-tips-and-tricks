GitHub sin secretos

GitHub Actions deploys to Azure via app registration Deployer. No secrets or certs stored in GitHub. Which credential?

A

A client secret with a 24-month expiration

B

A certificate, private key kept as a GitHub encrypted secret

A federated credential for GitHub Actions deploying Azure resources

D

A system-assigned managed identity on the GitHub-hosted runner

Por qué

La federated credential deja que GitHub Actions cambie su token por uno de Microsoft Entra sin guardar secretos.

A. Es un secreto, y 24 meses es el máximo permitido.

B. El cert es mejor, pero su private key en GitHub rompe la regla.

D. Un runner de GitHub no es recurso de Azure: no tiene managed identity.

Debrief de 45 segundos. Frase clave: "Managed identity no sale de Azure (salvo con Arc). Afuera: service principal con cert o federated". Delata: "GitHub Actions" y "no secrets stored". Si muchos eligieron D, repetir que el runner de GitHub no es un recurso de Azure.
