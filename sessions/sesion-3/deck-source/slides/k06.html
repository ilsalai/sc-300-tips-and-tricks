expenses.contoso.com con App Proxy

An App Proxy app must use https://expenses.contoso.com. The domain is already verified. What else do you need?

A

.cer certificate and an A record to the connector's public IP

B

Only a TXT record; Microsoft provides the certificate

PFX with the private key and a CNAME to the msappproxy.net address

D

Certificate on the connector server and inbound TCP 443 open

Por qué

Custom domain = certificado PFX con private key, subido en la página Application proxy de la app, más un CNAME al dominio msappproxy.net.

A. Un .cer no trae private key, y no se apunta a IPs de servers.

B. El TXT es para verificar el dominio, paso que ya está hecho.

D. El connector no recibe tráfico de internet: todo es outbound.
