Trampa 3 · Effective permissions

¿Quién resetea a quién?

"Helpdesk no resetea a los de arriba, y el Global Admin no ve Azure hasta que se eleva."

4

Global Admin y Privileged Authentication Admin: resetean a todos, incluidos miembros y owners de role-assignable groups.

3

User Administrator: resetea a User Admins, Helpdesk Admins, Password Admins y non-admins.

2

Helpdesk Administrator: resetea a Helpdesk Admins, Password Admins y non-admins. Nunca a un User Admin.

1

Password Administrator: solo non-admins, Directory Readers, Guest Inviter y otros Password Admins.

Entra roles vs Azure RBAC

Son dos mundos: el Global Admin no ve suscripciones hasta activar Access management for Azure resources. Eso le da User Access Administrator en el root scope. Al terminar, regresarlo a No.

Delata: "can't see any subscriptions", "assign Azure roles in every subscription".
