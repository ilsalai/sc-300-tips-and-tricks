Trampas 6 y 7 · External users

Guest, member, external, internal

"UserType es el nivel de permiso; Identities dice dónde se autentica. Guest Inviter brinca el candado de 'solo admins', pero no el de 'nadie'."

La cuenta externa

  • Member o Guest define la relación con la org. Cambiar a Member no la vuelve interna.
  • Para hacerla interna de verdad: Convert to internal user.
  • Cambió de empresa o de correo: reset redemption status. Conserva object ID, grupos y apps. Helpdesk Administrator basta.

Invitar

  • Allow list o block list, nunca las dos. No afecta a guests que ya redimieron; una invitación pendiente sí falla.
  • Bulk invite pide Email address to invite y Redirection url. Bulk create hace internos con password y no invita.
  • New-MgInvitation sin -SendInvitationMessage no manda correo.

Learn: User type · Reset redemption status · Allow or block list · Bulk invite
