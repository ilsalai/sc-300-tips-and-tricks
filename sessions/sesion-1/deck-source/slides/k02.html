El rol justo para el service desk

The service desk must reset passwords for non-admins and for other Helpdesk Admins, but never for User Admins. Least privilege: which role?

A

Password Administrator

Helpdesk Administrator

C

User Administrator

D

Authentication Administrator

Por qué

Helpdesk Administrator resetea a non-admins y a otros Helpdesk Admins, pero no a User Admins. Es el rol más chico que cumple exacto.

A. Password Admin no puede resetear a un Helpdesk Admin.

C. User Admin sí resetea a otros User Admins. Rompe el "never".

D. Suena a passwords, pero su foco son métodos de autenticación y no alcanza a Helpdesk Admins.

Debrief de 45 segundos. Palabras que delatan: "but never for User Admins" y "least privilege". Frase clave: "El de abajo nunca resetea al de arriba". Si muchos eligieron D, aclarar que Authentication Administrator no es un rol de passwords.
