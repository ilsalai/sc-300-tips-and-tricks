Cross-tenant sync Test connection fails: "The source tenant has not enabled automatic user consent with the target tenant". What do you do?

Source: outbound trust, automatically redeem invitations

B

Target: allow user synchronization into this tenant

C

Target: give the source admin Hybrid Identity Administrator

D

Source: enable outbound B2B direct connect

Por qué

El mensaje nombra al source y habla de automatic user consent: falta el automatic redemption outbound en el source.

B. Ese setting vive en el target y su error es otro: "The target tenant has not enabled inbound synchronization".

C. Cada admin trabaja en su propio tenant.

D. Direct connect es para Teams shared channels, no para sync.

Learn: Symptom: Test connection fails

Debrief de 45 segundos. Enseñar a leer el mensaje de error: qué tenant nombra. Frase clave: "El source empuja; el target solo abre la puerta". El error que nombra al source es outbound redemption; el que nombra al target es inbound allow sync.
