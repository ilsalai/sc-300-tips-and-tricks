El forest que no se ve

You acquired a forest with no connectivity to yours. 8,000 users must appear in your tenant, highly available, with minimal on-prem infra. Which tool?

Cloud Sync with three provisioning agents

B

A connector on the existing Connect Sync server

C

A second Connect Sync server in active mode

D

Cross-tenant synchronization

Por qué

Forests desconectados son escenario de Cloud Sync. Agentes ligeros, tres activos para HA, y convive con Connect Sync si cada objeto está en el scope de una sola herramienta.

B. El conector necesita conectividad con el forest. No hay.

C. Connect Sync es Active-Passive: un solo servidor activo por tenant.

D. Cross-tenant sync mueve usuarios entre tenants de Entra, no desde AD on-prem.
