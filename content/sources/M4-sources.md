# M4 Sources: Plan and automate identity governance (20 a 25%)

Fuente de verdad del alcance: skills outline oficial "as of April 27, 2026".
https://learn.microsoft.com/credentials/certifications/resources/study-guides/sc-300

Learning path oficial del dominio (4 módulos):
https://learn.microsoft.com/training/paths/plan-implement-identity-governance-strategy/

Cómo se validaron los deep links: cada página principal se leyó completa con la herramienta de Microsoft Learn, y el anchor se armó con el texto real del heading (minúsculas, espacios a guiones, sin signos). La mayoría de los anchors además salieron idénticos en los resultados del buscador oficial de Learn o en links internos de las mismas páginas. Se evitaron a propósito los anchors viejos que todavía dicen "azure-ad" en algunos links internos de Learn, porque el heading actual ya dice "Microsoft Entra".

Notas de vigencia (septiembre 2026):
- **Break-glass cambió de enfoque.** Learn ya no dice "sin MFA". Hoy pide passkey (FIDO2) o certificate-based authentication para cumplir la MFA obligatoria, con un método distinto al de los admins normales. Se excluyen de las políticas de Conditional Access que **bloquean o restringen** el sign-in. Las políticas en Report-only no necesitan exclusión. El rol Global Administrator va **active permanent** en PIM, no eligible.
- **PIM for Azure resources:** la experiencia nueva maneja los recursos de Azure sin onboarding. Los pasos de "Discover resources" y "Manage resource" (que asignan el service principal MS-PIM como User Access Administrator) son la experiencia legacy. En el examen todavía puede aparecer el discovery.
- **Licencias:** entitlement management y access reviews piden Microsoft Entra ID Governance o Microsoft Entra Suite. Algunas funciones siguen con P2. Las reviews de inactive users y la recomendación user-to-group affiliation piden ID Governance.
- **User Administrator ya no crea catalogs** ni maneja access packages en catalogs que no son suyos. Learn recomienda Identity Governance Administrator.
- En las policies de access package, la opción interna ahora se llama "For users, service principals, and agent identities in your directory" (por Microsoft Entra Agent ID). El toggle viejo "Enable new requests and assignments" hoy es "Who can request access: Self, Admin, Manager".
- Retención: audit y sign-ins, Free 7 días y P1/P2 30 días. Risky sign-ins: Free 7, P1 30, **P2 90 días**. El upgrade de licencia no recupera datos ya vencidos.
- La ruta del portal cambió a **Entra ID > Monitoring & health** (Sign-in logs, Audit logs, Diagnostic settings, Log Analytics, Workbooks).
