# M1 Sources: Implement and manage user identities (20 a 25%)

Fuente de verdad del alcance: skills outline oficial "as of April 27, 2026".
https://learn.microsoft.com/credentials/certifications/resources/study-guides/sc-300

Learning path oficial del dominio:
https://learn.microsoft.com/training/paths/implement-identity-management-solution/

Cómo se validaron los deep links: cada página se leyó completa con la herramienta de Microsoft Learn y el anchor se armó con el texto real del heading (minúsculas, espacios a guiones, sin signos). Varios anchors además salieron idénticos en los resultados del buscador oficial de Learn.

Notas de vigencia (septiembre 2026):
- La asignación de licencias a usuarios y grupos ahora se documenta en el **Microsoft 365 admin center**. La página vieja de Entra "licensing-groups-resolve-problems" redirige ahí.
- La tabla oficial Connect Sync vs Cloud Sync cambió: hoy marca **Exchange hybrid y group writeback v1 soportados en ambos**. Lo que sigue siendo solo de Connect Sync: device sync para hybrid join, configurar PTA y AD FS, sync rules avanzadas, más de 150K objetos por dominio.
